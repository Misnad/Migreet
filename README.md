# Migreet

A simple greeter for [greetd](https://git.sr.ht/~kennylevinsen/greetd) login manager. 

- https://git.sr.ht/~kennylevinsen/greetd
- https://wiki.archlinux.org/title/Greetd

Migreet is implemented in Rust with [Iced](https://iced.rs/), and is ment to be run on a Wayland compositer (like [niri](https://github.com/niri-wm/niri)).
